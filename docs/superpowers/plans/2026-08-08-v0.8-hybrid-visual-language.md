# V0.8 Hybrid Visual Language Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在不增加外部资产负担的前提下，把角色、敌人、经验粒和元素技能统一为“极简精品 65% + 霓虹元素 25% + 奥术符文 10%”的高可读视觉语言。

**Architecture:** 视觉仍由 Canvas 程序化绘制；用稳定的轮廓、层级和预算表控制可读性，再以有限辉光、符文和元素色作为强调。纯几何/颜色决策抽为可测试 helper，绘制实现保持在 `renderer.js`。

**Tech Stack:** Canvas 2D、JavaScript、Node test runner、Playwright 截图。
