# 元素幸存者 / Elemental Survivor

一款使用 Canvas 2D 制作的网页 Roguelite 小游戏。移动角色、自动攻击、收集元素能量，并通过三选一升级形成元素 Build。

## 在线试玩

https://baozhou941.github.io/elemental-survivor/

## 操作

- 电脑：WASD 或方向键移动，自动攻击。
- 手机：拖动屏幕左下角的虚拟摇杆，自动攻击。
- Esc：暂停或继续。

## 当前内容

- 3 种基础武器与约 10 项升级
- 3 种敌人
- 经验、升级三选一、元素反应
- 基础 HUD、粒子与音效反馈
- 暂停、游戏结束与重新开始

## 本地运行

```bash
npm install
npm run dev
```

打开终端中显示的本地地址。

## 测试

```bash
npm test
npm run test:e2e
```
