# Elemental Survivor V0.2 Plan

**Goal:** Make the frozen V0.1 slice more legible, fair, measurable, and Build-driven without broadening content beyond one experimental reaction.

## P0 — completed

- Preserve XP rewards and safe spawning under simultaneous-kill, orb-cap, and arena-corner edge cases.
- Increase Fire Tornado radius from 72 to 96, render the configured radius, and record activations, hits, and zero-hit activations.
- Record XP produced/collected, first kill/pickup/level-up timestamps, slow enemy-seconds, frame hitches, entity peaks, and last damage source.
- Show XP anticipation at 70% and 90%, and the lethal source on game over.
- Clear held input whenever play leaves the running state.
- Prevent duplicate loop callbacks across pause, resume, game over, and restart.

## P1 — completed

- Remove unsupported COMMON/RARE labels while retaining a unique ELEMENT REACTION label.
- Rename the radius-only Fireball upgrade from “爆燃” to “熔核膨胀”.
- Add a compact Fire + Wind combination hint on the Wind Blade unlock.
- Apply restrained Elemental Sigil readability changes: true-radius reaction ring, differentiated Wind Blade arc, quieter shake, stronger XP milestone feedback, and clearer upgrade labels.
- Make E2E death deterministic by steering its test player toward threats instead of relying on a timing boundary.

## P2 — completed

- Add a deterministic 30-seed balance runner and preserve its JSON report.
- Re-run the complete browser journey and a real three-minute browser session.

## LATER

- A second element reaction. V0.2 evidence first needs expert and human review; adding content now would hide whether the existing reaction is actually satisfying.
- A richer game-over Build recap, weighted upgrade pools, Boss, Elite, and more enemy behavior.
- Spatial-grid or pooling work unless measurements show a real entity-count, allocation, or frame-time bottleneck.

## Acceptance result

- Unit/integration/check suite: passed, 57/57 before final documentation packaging.
- E2E complete journey: passed, 1/1 in 43.7 seconds.
- Three-minute browser playtest: passed, 1/1; remained alive at 4/6 health.
- First level-up: 27.10 seconds in the representative browser run, slightly earlier than the 30–45 second target and retained pending review.
- Fire Tornado: 2.52 hits per activation, 28.6% zero-hit activations, 6.2% of total recorded damage.
- Reward, milestone, reaction, slow, hitch, damage-source, and entity-peak telemetry are present.
- Multiple Build viability remains unproven because V0.2 intentionally contains only one reaction and one representative browser route.
