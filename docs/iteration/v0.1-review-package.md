## Product goal

Elemental Survivor is a short browser Roguelite built around automatic attacks, visible 30–60 second growth, and element reactions that change weapon behaviour. V0.1 intentionally freezes scope after proving a complete three-minute run.

## Implemented scope

- One arena, one player, keyboard movement, automatic aiming/attacks.
- Fireball, Wind Blade, Ice Shard.
- Chaser, Swift and Brute enemies.
- XP drops, attraction and multi-level handling.
- Three-choice level-up modal with ten meaningful upgrades.
- Fire + Wind unlocks Fire Tornado.
- Hit, kill, XP, upgrade and reaction particles/audio feedback.
- HUD, pause/resume, game over and clean restart.
- Encounter Director, spatial grid collision, capped delta time and visibility pause.
- Read-only `?test=1` snapshots and local run telemetry.

## Codex playtest observations

### Working

- Start screen explains the complete control model without a tutorial wall.
- First kills and XP arrive well inside ten seconds.
- First upgrade target is about 30–45 seconds; captured run reached it around 34 seconds.
- Player, hazards, enemies and pickups remain visually separable at V0.1 density.
- Fire Tornado is a visible behaviour change rather than a percentage-only bonus.
- Pause, death and restart communicate state clearly and restart without stale entities.

### Weak or uncertain

- The first 20–30 seconds only have Fireball, so choice anticipation depends heavily on XP pace.
- V0.1 only proves one reaction and cannot yet prove several equally viable builds.
- Fire Tornado damage share was low in the sample run despite high activation count; its control value is not yet measured.
- Three enemy silhouettes are readable but behaviour contrast is still modest.
- Audio is generated and functional, but not yet a mature sound design pass.
- A stationary player dies rapidly, as intended; fairness of the first contact needs human-player feedback.
