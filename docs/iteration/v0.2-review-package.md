# V0.2 Review Package

Date: 2026-07-31

## Review question

Did V0.2 make the same small game more legible, fair, measurable, and Build-driven, or did it merely add instrumentation? Review evidence separately from inference and propose at most three next changes.

## Changes since V0.1

- Fixed simultaneous XP loss, XP-orb cap loss, unsafe corner spawning, duplicate loop scheduling, held-input leakage, and boundary-dependent E2E death.
- Enlarged Fire Tornado from radius 72 to 96 without increasing damage; aligned rendering with configured area.
- Added XP milestone feedback, concise element-combination hint, honest upgrade labels, lethal-source recap, restrained shake, and clearer Wind Blade/reaction visuals.
- Added reward-conservation, milestone, slow-utility, reaction-efficiency, frame-hitch, damage-source, and entity-peak telemetry.
- Added deterministic 30-seed balance simulation while preserving a separate real-browser three-minute run.
- Kept one reaction only. Boss, Elite, meta progression, new maps, shops, and broad content remain out of scope.

## Fresh evidence

- `npm run check`: 57/57 Node tests passed.
- `npm run test:e2e`: 1/1 complete journey passed in 43.7 seconds.
- `npm run test:playtest`: 1/1 real-browser three-minute run passed.
- `npm run test:balance`: 30/30 deterministic seeds completed 180 seconds.

Representative browser run: level 8, 240 kills, 4/6 health, first level-up at 27.10 seconds, average 59.56 FPS, zero recorded hitches, and peaks of 25 enemies / 8 projectiles / 58 particles.

Fire Tornado recorded 21 activations, 53 hits, 6 zero-hit activations, and 477 damage: 2.52 hits per activation, 28.6% zero-hit activations, and 6.2% of total damage.

## Known evidence limits

- The 30-seed steering bot took no damage, so it validates deterministic progression and caps, not human difficulty.
- The browser playtest bot took two damage, but neither automation nor expert review proves first-time comprehension, fun, or replay desire.
- The representative first level-up at 27.10 seconds is slightly earlier than the 30–45 second target. No XP retune was made before review.
- Six of 21 reaction activations hit nothing. The numerical acceptance gate passes, but the wasted activations may still feel weak.
- Multiple viable Builds and “one more run” motivation remain unproven with only one reaction.

## Review boundary

Prioritize correctness, first-30-second pacing, Fire Tornado impact, battlefield clarity, choice quality, and replay motivation. Do not expand into accounts, stores, achievements, meta progression, many maps, or dozens of upgrades. Do not claim local execution unless execution evidence is provided.
