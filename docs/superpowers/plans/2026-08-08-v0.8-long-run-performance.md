# V0.8 Long-run Performance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让无尽模式在高实体数量和 10 分钟以上长局中保持稳定帧时，同时保持现有碰撞、暂停和重开语义。

**Architecture:** 复用现有 `SpatialGrid` 缩小精确碰撞候选集；渲染器在相机视口外跳过绘制；HUD 只在状态变化时写 DOM；遥测同时保留累计指标并新增固定窗口指标。每项均先添加失败测试，再做最小实现。

**Tech Stack:** JavaScript ES modules、Canvas 2D、Node test runner、Playwright。
