# Elemental Survivor V0.4 Plan

**Goal:** Make the first upgrade a real Wind-versus-Ice Build fork, repair Thermal Shock trigger semantics, and reduce XP visual noise without expanding content.

## P0 — completed

- Guarantee Wind Blade and Ice Shard in the first three-card offer.
- Lock each run to its first selected elemental reaction and remove the alternate reaction from later offers.
- Guarantee the eligible reaction in the next offer so route formation is testable rather than luck-dependent.
- Allow a lethal Fireball to trigger Thermal Shock on its slowed target before final reward cleanup.
- Preserve exactly-once kill, XP, reaction, and per-enemy cooldown behavior.

## P1 — completed

- Clear renderer shake, flash, hurt cue, and burst state on start/restart.
- Keep far XP as a faint hollow diamond; add glow and a center mark only inside pickup proximity.
- Show one first-pickup hint and exact Fire/Wind and Fire/Ice recipe language.
- Add a single alternate-route goal to game over.
- Harden deterministic E2E defeat through a `?test=1`-only app boundary; production URLs expose no test API.

## Verification result

- `npm run check`: 69/69 passed.
- `npm run test:e2e`: 1/1 passed, including movement, attack, XP, upgrade, pause/resume, deterministic defeat, restart, and loop continuity.
- `npm run test:balance`: 30/30 automatic 180-second runs survived; used only for invariants and regression evidence.
- Wind route: 30/30 formed Fire Tornado within 90 seconds; 1.07 hits/activation, 3.23% damage share, 0/30 no-hit runs.
- Ice route: 30/30 formed Thermal Shock within 90 seconds; 1.30 hits/activation, 4.73% damage share, 1/30 no-hit runs due to late unlock.
- Real Chromium: 180.02 seconds, level 8, 231 kills, 6/6 health; first upgrade 22.93 seconds.
- Fire Tornado in browser: 24 activations, 61 hits, 8 zero-hit activations, 549 damage / 6.86% share.
- Performance: 59.70 average FPS, zero hitches; peaks 29 enemies, 5 projectiles, 35 particles.

## Acceptance decision

The implementation meets the objective engineering, route-formation, reaction-reliability, and performance gates. The first choice now changes the run's reaction outcome, while the two routes retain distinct continuous-orbit versus status-triggered burst behavior. Human fun, clarity, fairness, and replay desire remain unverified.
