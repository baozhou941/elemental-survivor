# V0.5 实施计划｜路线理解与可复盘结算

日期：2026-08-01  
范围：V0.4 评审后的最小证据迭代  
Git：Local only

## 目标

V0.5 不添加玩法内容。它只解决两个已被五位专家共同指出但尚未证明的问题：玩家在投入 Build 前是否知道单反应槽规则，以及一局结束后是否能说清自己形成了什么路线。

## P0

- 第一次升级显示单反应槽规则。
- Wind/Ice 卡预告反应配方，第三项说明不锁路线。
- 结算显示本局路线、反应激活与命中数据。
- 删除建议玩家下一局换路线的文案。
- E2E 覆盖上述可见规则和正式 URL 测试接口隔离。

## P1

- 同一步多伤害下，Thermal Shock 的死亡、击杀、XP、掉落和里程碑各结算一次。
- 50 次 GameLoop 启停压力下，最多一个待调度 RAF，停止后的旧回调不再推进。
- 补一局 Ice 路线真实 Chromium 三分钟证据。

## P2

- 建立真人盲测记录模板；本轮不实现上传、持久化或产品内埋点。
- 观察卡片附加说明是否造成升级弹窗信息过载。

## Rejected

- XP 60→90 或其他数值调整。
- 新元素、反应、敌人、Boss、地图、Meta、成就或设置页。
- 更强 VFX、新图片资产、对象池、空间网格和架构重写。

## 实施与验证顺序

1. 先写会失败的 E2E/逻辑回归测试。
2. 最小修改升级面板与结算展示。
3. 补工程边界测试并执行全量检查。
4. 执行 Wind/Ice 路线仿真、180 秒平衡仿真和真实 Chromium 试玩。
5. 保存 V0.5 截图与遥测，逐项回答版本十问。

## 真人盲测协议

- 不在试玩前解释 XP、自动攻击、反应槽或路线。
- 观察者只记录，不在玩家决定是否重开前提示另一条路线。
- 记录：首次移动、首次击杀、首次 XP、首次升级时间；能否复述一条反应；能否说明首个反应锁路线；是否自发重开；从失败到重开的时间；第二局是否换路线。
- 5 人可用性门槛：4/5 能说明“首个反应锁定本局路线”，无人反馈规则在投入后才告知。
- 正式目标：12～20 名新玩家，≥80% 理解移动/XP，首次升级中位数 25～40 秒，≥70% 能描述反应，≥60% 自发重开，重开者中 ≥60% 主动换路线。

## 执行结果（2026-08-01）

- P0 完成：首次升级显示单反应槽规则、两条路线配方预告与中性选项说明；结算显示路线、激活、命中；已移除“下局目标”。
- P1 工程项完成：致死 Thermal Shock 精确结算一次；50 次 GameLoop 启停与 50 次 run 重启均有回归测试。
- 工程验证通过：`npm run check` 为 75/75；`npm run test:e2e` 为 2/2，正式 URL 不暴露测试控制 API。
- Wind Chromium 自动试玩达到 180.07 秒，等级 7、击杀 238、火焰龙卷 17 次激活/69 命中。
- Ice Chromium 自动试玩止于 169.52 秒，等级 8、击杀 219、霜爆 39 次激活/67 命中；未达到本计划的三分钟浏览器门槛。
- 30 种子 × 180 秒验证：Wind 30/30 存活；Ice 18/30 存活（60%）。路线差异进入下一轮 P0，不在 V0.5 内临时改数值。
- P2 真人盲测尚未执行；自动化数据不能证明“好玩”、规则已被真人理解或失败后愿意再来一局。
